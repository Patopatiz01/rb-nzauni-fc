# RB Nzauni FC — Static Professional Website

## Run
Open `index.html` in any browser. No PHP, database or installation required.

## Edit content
- `app.js`: edit `matches`, `table`, and `players` arrays. These contain demonstration records, not verified match or squad information.
- `index.html`: edit the About, News, Gallery, Sponsors and Contact sections.
- `assets/logo.png`: official supplied club crest.
- `styles.css`: theme colors, fonts, layout and responsiveness.

## Hosting from a phone
Extract the ZIP in your phone's Files app. Upload `index.html`, `styles.css`, `app.js`, and the `assets` folder to the public website folder of any static host, such as GitHub Pages, Netlify, or an ordinary web host's `htdocs` folder. Keep the same file structure.

## Important
This is a static website. The contact link opens WhatsApp. There is no server-side registration, payment processing or admin dashboard. Replace all illustrative fixtures, standings, player cards and gallery placeholders before public launch.
